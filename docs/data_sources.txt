[G] ★ 119 출동 평균 도착시간 (소방 안전 빅데이터 플랫폼) ← 핵심 차별 피처
    URL: https://www.bigdata-119.kr/
    절차: 회원가입 → 데이터 신청 → 승인(1~3일) → 다운로드

    필요 데이터:
    - 서울시 119 화재 출동 현황 (2021~2023)
    - 저장 경로: data/raw/fire_dispatch_seoul.csv
    - 필수 컬럼: 발생동코드(행정동), 신고접수시각, 현장도착시각
    - 파생: 도착시간 = 현장도착시각 - 신고접수시각 (분 단위)
    - 집계: 행정동별 평균 도착시간 → dispatch_time_avg_min

    활용:
    - "화재 이력 ↑ + 소방 도착시간 ↑" = 최고 위험 공백 지역 식별
    - 기존 소방청 서비스 미제공 지표 → 핵심 차별점

    ※ 신청 시 목적: "서울시 화재 안전 취약지역 분석 및 소방 자원 배분 연구"
    ※ 빅데이터 플랫폼 내 검색어: "출동", "화재출동", "119출동현황"

[H] ★ 1인가구 비율 (행정안전부 주민등록 인구통계)
    URL: https://jumin.mois.go.kr/
    절차: 회원가입 없이 다운로드 가능
    저장 경로: data/raw/population_household.xlsx

    다운로드 경로:
    주민등록 인구통계 → 세대원수별 세대수 → 행정동 단위 선택
    → 2023년 12월 기준 → 서울특별시 전체 → 엑셀 다운로드

    필수 컬럼:
    - 행정동코드, 행정동명
    - 1인세대수, 총세대수
    - 파생: 1인가구비율 = 1인세대수 / 총세대수

    활용:
    - 고령 1인가구 밀집 지역 = 화재 발생 시 자력 대피 불가 계층
    - ratio_65plus × 1인가구비율 → 취약계층 복합 지수

    ※ [C] 항목의 population_household.xlsx와 동일 파일
